OSS-DBS v2: Simulation Platform for Biophysical Modelling of Deep Brain Stimulation.

Julius Zimmermann, Jan Philipp Payonk, Lam Vien Che, Joachim Schöberl, Till A Dembek, Andreas Horn, Ursula van Rienen, Konstantin Butenko
medRxiv : the preprint server for health sciences · 2026-10-13 · doi:10.64898/2026.10.10.26365197
Pre-clinicalPeer reviewedConnectivity / synchronyComputational / whole-brain modellingBrain stimulationPreprocessing / source / tools

Background Deep brain stimulation (DBS) is a well-established therapy for various neurological disorders.

Methods In this article, we present the open-source platform OSS-DBS v2 that enables researchers and clinicians to build such biophysical models.

Results Its application programming interface facilitates integration of external data workflows, such as impedance measurements. Furthermore, an integration with the Lead-DBS toolbox offered a straightforward graphical user interface for stimulation volume and pathway activation modelling, further complemented by an optimization framework.

Conclusion OSS-DBS v2 relies entirely on open-source software, supports all major operating systems and is designed for efficient execution on consumer-grade hardware.
