From Intrinsic Topography to Cognitive Prediction: Benchmarking Approaches to Personalized Cortical Parcellation.

Yusuf Cosku Inceler, Micha Burkhardt, Carsten Gießing, Daniel Kristanto
bioRxiv : the preprint server for biology · 2026-10-12 · doi:10.64898/2026.10.09.758001
fMRIClinicalPeer reviewedConnectivity / synchronyInformation theory / complexityComputational / whole-brain modellingPreprocessing / source / toolsMachine learning / AI

Background Personalized functional magnetic resonance imaging (fMRI) adapts cortical parcellations to individual functional anatomy.

Methods Using the Human Connectome Project Young Adult dataset (N = 947), we compared five personalized parcellation methods and a standard group-level atlas.

Results We also examined whether connectivity and topographic features were associated with and predicted general intelligence (g). Using kernel ridge regression, functional connectivity significantly predicted g, with the group atlas yielding the highest predictive accuracy, consistent with a potential advantage of cross-individual spatial correspondence for edge-wise prediction.

Conclusion We conclude that personalized parcellation approaches are associated with distinct trade-offs in spatial correspondence, topographic variability, and downstream predictive utility.
