M3-Platform: An open-source unified GUI framework for multimodal physiological signal analysis.

Wenqing Zhou, Zhejun Zhang, Huiying Chen, Chengyi Zhao, Lin Zhang, Lei Li
Computer methods and programs in biomedicine · 2026-11-24 · doi:10.1016/j.cmpb.2026.109720
Peer reviewedInformation theory / complexityComputational / whole-brain modellingPreprocessing / source / tools#multimodal analysis#eeg fnirs#open-source software

Aim To introduce an open-source GUI platform that integrates EEG, fNIRS and eye-tracking analysis with questionnaire data in one interface.

Methods Modular software architecture linking data organisation, preprocessing, analysis, visualisation and export, plus a module for deploying pre-trained models; evaluated for function, performance against reference tools and usability.

Results The platform executed cross-modal workflows and model inference, matched reference tools under matched settings, and showed acceptable usability and manageable workload in a user study.

Conclusion The authors present M3-Platform as an extensible GUI research environment for multimodal physiological-signal analysis.

Why it matters for you: A single GUI for combining EEG with other physiological signals could simplify multimodal workflows you may want to adopt, though it is not tied to your PET or psychedelic work.
