mriqc 26.0.0 released

GitHub · nipreps/mriqc · 2026-11-05

- Docker: docker pull nipreps/mriqc:26.0.0 (linux/amd64 and linux/arm64) - PyPI: pip install mriqc==26.0.0 (Python 3.13 or newer) The first release of the 26.x series, and the first since 24.0.2 (25.0.0rc0 was never finalized). MRIQC now requires Python 3.13 or newer, following SPEC 0 (https://scientific-python.org/specs/spec-0000/), and its container image runs on linux/amd64 and linux/arm64 .
