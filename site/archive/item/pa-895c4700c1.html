Somnus, a tunable, open-source platform for automated EEG sleep scoring in physiological and disease mouse models.

Josh Brenner, Matthew S Caudill, Huda Y Zoghbi
bioRxiv : the preprint server for biology · 2026-10-12 · doi:10.64898/2026.10.05.756738
EEGEpilepsyPre-clinicalPeer reviewedComputational / whole-brain modellingMachine learning / AIPre-clinical / invasive

Background Many studies using mouse models of human brain disorders rely on extended recordings of brain electrical activity through electroencephalogram, or EEG.

Methods Manual annotation is highly labor-intensive, often requiring hours per subject. Somnus is an open-source Python package designed to automate rodent sleep staging using EEG, muscle activity (EMG), and optional video-tracking data.

Results A central feature of Somnus is its capacity for rapid adaptation to pathological sleep structure. The software provides a graphical interface that directs researchers to the specific epochs where the base model is least certain.
